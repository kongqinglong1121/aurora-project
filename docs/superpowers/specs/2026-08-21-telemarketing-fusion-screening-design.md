# 纯机获客 20%+ 定价占比治理：内外部数据融合精筛设计

**日期：** 2026-08-21  
**状态：** 待业务确认  
**路径分类：** Architectural  
**选定方案：** 方案 3 — 约束双轨（矩阵主名单 + 多策略探索/补量 + 配额合并器）

---

## 1. 背景与问题

### 1.1 现象

纯机获客（IVR 等）名单中，定价落在 **20%+** 的用户占比约 **74%**，显著高于健康结构。风险侧将进一步精细化客群：部分未激活人群将被确认为 **高风险不可经营**，后续不再给营销补贴，也大概率不再进入电销。

### 1.2 核心矛盾

| 层 | 问题 | 本质 |
|---|---|---|
| 供给结构 | 20%+ 占比过高 | 名单资质结构劣化 |
| 政策冲击 | 风控确认不可经营客群 | 电销供给将被外生收缩 |
| 算法动作 | 电销前做资质精筛 | 需风控前置，而非事后缩量 |
| 副作用 | 资质提升后信贷营销响应下降 | 单优化资质会伤害转化 |
| 决策冲突 | 压占比 vs 保量 vs 控成本 | 必须分层约束 |
| 运营形态 | 要可解释主量 + 可探索补量 | 双轨圈选 |

### 1.3 优化目标（优先级已确认）

1. **最高优先级（A）：** 合并外呼名单的 **20%+ 定价占比 ≤ 目标占比**。目标占比由业务与量化基于 **全批次（含非列表批次）占比对齐** 后确认，作为系统硬参数写入，不由模型自行「学出」。
2. **落地保障（B）：** 转化量不低于约定底线。
3. **落地保障（C）：** ROI / 单位成本落在约定可行域内。
4. **形态（D）：** 分层目标——在 A 硬顶下，用 B/C 约束可行域；核心量走矩阵主名单，边缘用探索轨补量。

---

## 2. 设计原则

1. **风控硬集与算法软筛分离：** 不可经营客群由风控确认后必剔，不进入分数博弈。
2. **风控前置：** 算法在电销前完成人群资质筛选，主动对齐可经营边界。
3. **双分职责分离：** 资质分服务结构（A）；响应分服务转化（B/C）。
4. **双轨圈选：** 矩阵主名单可解释；多策略副名单负责探索与补量；**仅配额合并器对 A/B/C 总负责**。
5. **外数先探索后晋升：** 新外部数据源先走副名单验证，再进入主分/矩阵。
6. **防泄漏：** 当期定价档不作为 S_qual 训练/推理主特征；特征须满足「电销决策前可得」时间切割。

        │

        │
        ├──────────────────┬────────────────────┐

[3a] 矩阵主名单      [3b] 多策略副名单      [3c] 诊断看板

        │                  │

## 4. 数据源边界

### 4.1 现有数据源

| 数据源 | 类型 | 主要覆盖 | 边界 / 盲区 |
|---|---|---|---|
| 风控「不可经营」客群确认 | 内-政策 | 未激活中明确不可经营 | 只解决硬剔除；不解释 20%+ 结构，也不预测响应 |
| A 卡分 | 内-信用 | 违约/资质主轴 | 偏风险，弱营销响应；对「高资质低响应」不敏感 |
| 用户资质评分 | 内-资质 | 用户资质表象/综合资质 | 易与 A 卡共线；对利率档、共债、多头解释有限 |
| 百行 · 利率等级偏好等标签 | 外-征信系 | 利率偏好、部分信贷行为画像 | 覆盖率/时效/授权受限；不等于定价结果，更不等于可经营 |
| 朴道 · 利率等级偏好等标签 | 外-征信系 | 与百行互补的偏好/等级 | 与百行重叠时增益递减；字段口径需对齐后再融合 |
| 电销批次/名单与触达结果 | 内-运营 | 批次、渠道、接通/意向/转化 | 强选择偏差；矩阵格子需控置信度 |
| 定价档（含 20%+） | 内-定价结果 | 结构监控与目标占比 | 结果变量；不宜裸进模型作主特征（泄漏/循环） |

**现有能力边界：** 已具备风险/资质主轴 + 两家外数利率偏好 + 运营反馈；缺口在共债/多头深度、收入与还款能力代理、反欺诈与可联性、营销响应专用特征、以及授权外数的稳定覆盖。

### 4.2 相对目标的缺口

| 目标 | 现有支撑 | 缺口 |
|---|---|---|
| 压 20%+ 占比（A） | 部分（资质闸门） | 缺「将落在高定价」的前置因子（共债、还款压力、多头申请密度等） |
| 转化量底线（B） | 弱 | 响应特征薄；高资质人群触达匹配不足 |
| ROI/成本（C） | 弱 | 缺成本归因与可联性/空号等降空耗特征 |
| 风控前置对齐 | 政策硬集有 | 算法特征与风控规则重叠度需定期审计 |

### 4.3 可拓展外部数据

**P0 — 直接服务降 20%+ / 不可经营对齐**

- 多头/共债类（合规产品中的申请/借贷密度）
- 百行/朴道扩字段（还款表现、信贷活跃度、机构偏好等；先挖已签约源）
- 逾期/还款压力代理（合规许可下）

**P1 — 服务响应与可联性（保 B、降空耗）**

- 可联性/空号/沉默号
- 营销响应类外数（消费/金融活跃、信贷意向分等，需授权）
- 设备/环境风险（降虚假与低价值骚扰，服务 C）

**P2 — 边界拓展但依赖合规与商务**

- 收入/稳定度代理（社保公积金等合作）
- 体系内合规可打通的场景消费与生态行为
- 区域/行业宏观（仅适合分层策略，不适合个人主分）

**不优先 / 禁止**

- 无时间切割地把定价档当主特征预测「谁是 20%+」
- 无授权爬取、灰产号码库、非合规征信
- 与 A 卡高度同构的第二家「泛信用分」（边际薄）

### 4.4 融合与准入原则

1. 硬集只用风控确认字段；外数不替代政策剔除。
2. `S_qual`：A 卡 + 用户资质评分 + 百行/朴道（+P0）。
3. `S_resp`：内触达反馈 + P1；控制与风险特征共线。
4. 新外数准入：覆盖率、授权率、稳定性、对 20%+ / 转化的增量效果；不达标不进主分。
5. 探索轨作为外数试验田；验证后再晋升。

## 5. 分数定义与模型职责

### 5.1 双分定义

| 分数 | 优化对象 | 主输入 | 明确不做什么 |
|---|---|---|---|
| **S_qual（资质分）** | 对齐可经营性；压低 20%+ 结构 | A 卡分、用户资质评分、百行/朴道利率偏好等、P0 | 不直接最大化接通或动支 |
| **S_resp（响应分）** | 可经营池内的营销响应/转化倾向 | 历史触达与转化、可联性、意向/活跃（P1）、渠道上下文 | 不承担「是否不可经营」裁决 |

### 5.2 S_qual

- **标签：** 优先贴近风控「不可经营」及历史停补/停电销结果；标签不足时用合规代理起步，就绪后校准。
- **输出：** 连续分 + 分位数；阈值 **θ_q** 由「合并后 20%+ 占比 vs 目标占比」反推调节。
- **防泄漏：** 定价档、当期定价结果不进训练主特征。
- **融合：** 控制 A 卡与用户资质评分等共线性，避免同构信用分堆叠。

### 5.3 S_resp

- **标签：** 主标签建议为动支/授信成功等价值事件；辅标签为接通、有效意向。
- **样本：** 必须覆盖高 S_qual 人群。
- **解耦：** 控制风险特征权重或做正交化，避免与 S_qual 排名塌缩。
- **验收焦点：** 「高资质 × 原低响应」区间的 lift，而非仅全量 AUC。

### 5.4 冲突处理

S_qual 高且 S_resp 极低：默认不进主名单；仅小配额探索或沉寂，除非该格历史转化置信度足够。

## 6. 矩阵 × 多策略 × 配额合并

### 6.1 矩阵主名单

- **分箱：** **S_qual × S_resp = 10×10**。
- **格子指标：** 历史转化率、样本量、置信下界（如 Wilson）；成本/ROI 为辅。
- **选格：** 转化下界达标，且不破坏日目标下的 20%+ 结构贡献；高资质×低响应默认不进主量。
- **格内排序：** 按 S_resp（或期望转化）取满主名单配额。
- **冷格：** 样本不足不进主名单；可聚合展示或丢探索轨。
- **稀疏性：** 100 格冷格预期较多；主名单决策必须用置信下界。必要时允许「5×5 聚合决策 / 10×10 诊断展示」作为运维降级，但不改变默认设计分箱为 10×10。

### 6.2 多策略副名单

- 职责：补 B、探数据边界、验证新外数；**不对 A 单独负责**。
- 类型示例：高资质中响应边缘补量；单源强信号；新外数试验田；渠道/话术匹配试验。
- 约束：单日探索配额上限；单策略可熔断；策略 ID 可归因。

### 6.3 配额合并器

1. 上游已完成风控硬剔。
2. 主名单优先装入，滚动计算合并池 20%+ 占比；触顶则停装或只装低 20%+ 贡献用户。
3. 剩余容量给探索轨，同样受 A 硬顶约束。
4. 若仍不满足 B：在 **不突破 A** 前提下按边际转化贡献释放次优格/策略；仍不够则 A/B 冲突告警，人工决定是否调 θ_q 或接受掉量。
5. 同步校验 C；破线削减高成本低转化格/策略。
6. 去重：多策略命中同一用户，保留优先级最高且成本最低的一条并记归因。

### 6.4 节奏

| 节奏 | 调整对象 |
|---|---|
| 日 | 配额、熔断、A 占比监控 |
| 周 | θ_q、选格集合、主/探配比、策略升降级 |

## 7. 监控、验收与兜底

### 7.1 日监控

- 20%+ 占比 vs 目标（A）
- 转化量 vs 底线（B）
- 单位成本/ROI vs 上限（C）
- 主/探占比、去重率
- 10×10 各格样本量与转化下界
- 外数覆盖率/授权率/延迟

### 7.2 上线验收门禁

相对现行基线（同周期、同容量口径）：

1. A：20%+ 占比 ≤ 量化确认的目标占比（硬）
2. B：转化量不低于底线（或跌幅 ≤ 约定容忍）
3. C：ROI/单位成本落在约定带
4. 风控硬集漏网率抽检 ≈ 0
5. 主名单可解释；探索可归因、可熔断
6. S_qual 特征时间切割审计通过

### 7.3 风险兜底

| 风险 | 兜底 |
|---|---|
| 资质↑响应↓ 导致 B 破线 | 探索配额短暂上升；次优格有限释放；**不先破 A**；升级人工决策 |
| 10×10 过碎 | 置信下界；冷格禁用；可临时 5×5 聚合决策 |
| 外数抖动 | 单源熔断；回退 A 卡 + 用户资质评分 |
| 与风控规则重叠砍量 | 月度重叠审计；重复信号降权 |
| 探索刷量 | 单策略日上限 + 效果熔断 + 去重 |

## 8. 落地顺序（设计层）

1. 风控硬集落地 + 目标占比参数写入（量化对齐完成后）
2. S_qual（现有源）+ θ_q 调到 A 近目标
3. S_resp 升级，建立 10×10 矩阵主名单
4. 配额合并器上线（先主后探）
5. 外数按 P0→P1 进探索轨，验证后晋升主分/矩阵

---

## 9. 待业务/量化填入的参数（非设计未决）

以下不影响架构选定，但上线前必须赋值：

- 目标 20%+ 占比（全批次对齐结果）
- 转化量底线与统计口径
- ROI/单位成本上限与口径
- 日外呼容量与主/探默认配额比
- S_resp 主标签定义（动支/授信成功等）
- 矩阵选格的转化下界门槛

---

## 10. 明确不在本期范围

- 替代风控做不可经营最终裁决
- 单效用联合分替代双轨（已否决为方案 2）
- 无合规前提的外数接入
- 用定价结果反训资质主模型且无时间切割
